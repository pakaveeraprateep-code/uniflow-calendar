# UniFlow · ไฟล์ประกอบ

ที่เก็บนี้มีหน้าตัวอย่างสำหรับทดลองฟีเจอร์ของแอป **UniFlow** ไม่ใช่ช่องทางทางการของมหาวิทยาลัยใด

## นโยบายความเป็นส่วนตัว

[PRIVACY.md](PRIVACY.md) · ใช้เป็นลิงก์นโยบายความเป็นส่วนตัวของแอปใน App Store

## หน้าตารางเรียนตัวอย่าง

`demo/index.html` เป็นหน้าตารางเรียน**สมมติ** ใช้ทดลองฟีเจอร์ "นำเข้าตารางเรียน"
เปิดหน้านี้ใน Safari แล้วกดแชร์ไปที่ UniFlow ได้เลย ใช้สาธิตโดยไม่ต้องเปิดข้อมูลนักศึกษาจริง

## ปฏิทินการศึกษา

แอป UniFlow **ไม่ได้โหลดปฏิทินจากที่นี่แล้ว** ทุกมหาวิทยาลัยใช้วิธีเดียวกัน:
เปิดหน้าเว็บหรือไฟล์ PDF ปฏิทินการศึกษาของมหาวิทยาลัยตัวเองใน Safari → แชร์ → UniFlow → ตรวจวันที่แล้วนำเข้า

`lru-regular.json` และ `tools/validate.py` เก็บไว้เป็นตัวอย่างรูปแบบข้อมูลเท่านั้น
