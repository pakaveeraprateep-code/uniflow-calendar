# ปฏิทินการศึกษาสำหรับแอป UniFlow

ไฟล์ในที่นี้คือวันสำคัญของปฏิทินการศึกษา (เปิดเทอม ลงทะเบียน จ่ายค่าเทอม ถอนรายวิชา สอบ วันหยุด) ที่แอป **UniFlow** โหลดไปแสดงในปฏิทินและตั้งแจ้งเตือน

- ข้อมูลพิมพ์จาก **ประกาศที่มหาวิทยาลัยเผยแพร่ต่อสาธารณะ** และบอกแหล่งที่มาไว้ในไฟล์
- ที่นี่**ไม่ใช่**ช่องทางทางการของมหาวิทยาลัย และไม่ได้เชื่อมกับระบบของมหาวิทยาลัย โปรดตรวจสอบวันที่กับประกาศของมหาวิทยาลัยเสมอ
- แอปโหลดไฟล์นี้วันละครั้ง ไม่ส่งข้อมูลของผู้ใช้มาที่นี่

| ไฟล์ | ปฏิทิน | แหล่งที่มา |
|---|---|---|
| `lru-regular.json` | ม.ราชภัฏเลย ภาคปกติ | https://academic.lru.ac.th/th/?page_id=3040 |

## วิธีอัปเดตเมื่อมหาวิทยาลัยประกาศปฏิทินใหม่

1. เพิ่มรายการใน `events` (วันที่เป็น **ค.ศ.** เช่น 2570 = `2027`) และเปลี่ยน `updated` เป็นวันที่แก้ไฟล์
2. ตรวจไฟล์: `python3 tools/validate.py lru-regular.json` ต้องขึ้น ✅
3. commit แล้ว push เข้า `main` แอปของทุกคนจะได้ปฏิทินใหม่ภายใน 1 วัน (ไม่ต้องออกแอปเวอร์ชันใหม่)

ถ้าไฟล์ผิดรูปแบบ แอปจะไม่ใช้ และใช้ข้อมูลเดิมต่อ

`kind` ที่ใช้ได้: `termStart` เปิดเทอม · `termBreak` ปิดเทอม · `registration` ลงทะเบียน · `payment` จ่ายค่าเทอม · `withdraw` ถอนรายวิชา · `exam` ช่วงสอบ · `holiday` วันหยุด · `makeup` สัปดาห์ชดเชย
